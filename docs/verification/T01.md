## Standards

Independent review found one ADR-0003 breach: service-grant state/policy originally lived in Identity. Fixed by moving it into an implemented ServiceAccess module with its own schema/context. Identity supplies verification/block state through `IAccountState`; Classroom consumes `IAccountAccess`. Identity persistence implements the `ILoginSessions` application port.

One optional smell remains: server access status is represented by strings. The TypeScript consumer uses an explicit status union. No remaining material documented-standard breaches were found after review.

## Spec

Independent review found production HTTPS forwarding and Jenkins teardown credential-scope issues. Both were fixed: TLS terminates at nginx, backend accepts forwarded protocol from its allowlisted proxy, and cleanup binds the PostgreSQL credential. Backend static IP was removed; Docker's automatic IP pool is separate from nginx's fixed address to prevent collisions with database/backend/one-off containers. These fixes were checked again; no remaining material spec blockers were reported.

## Limits

Jenkins server execution was not available; its build/test commands and Compose services were exercised locally, but no Jenkins build is claimed. TLS verification used a self-signed local certificate, not a public deployment. Registration, verification/recovery email flows, Admin TOTP UI, approval, commercial periods and AI quotas remain follow-up tickets. Development provisioning is explicit and restricted to Development; it is not a public registration or production approval API.
