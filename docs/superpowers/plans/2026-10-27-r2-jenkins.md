# R2 Jenkins Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Jenkins chỉ nghiệm thu thành công khi API/browser thực sự xuất và tải PDF từ R2 test, có bằng chứng và cleanup theo run.

**Architecture:** Giữ adapter S3 và metadata hiện có; bổ sung prefix tùy chọn cho object vật lý. Công cụ CI .NET dùng cùng SDK quản lý prefix test và tổng hợp bằng chứng; Jenkins chịu trách nhiệm credentials, thứ tự chạy và cleanup.

**Tech Stack:** .NET 10, AWSSDK.S3 hiện có, xUnit, React/TypeScript, Playwright, Jenkins Declarative Pipeline, PostgreSQL Docker.

**Spec:** [Thiết kế đã duyệt](../specs/2026-10-27-r2-jenkins-design.md).

## Global Constraints

- Không dùng production và không tạo/xóa bucket; bucket test được cấp trước.
- Prefix run có dạng `ekt-ci/<run-id>/`; cleanup không được chạm tới prefix khác.
- Prefix lưu trữ mặc định rỗng; giữ đường dẫn object hiện hữu và không đổi schema metadata.
- Không lưu PDF, secrets, token, cookies, trace hoặc backend logs chưa lọc trong artifacts.
- Thiếu secrets/artifacts, skipped tests hoặc cleanup lỗi phải chặn nghiệm thu thành công.
- Chỉ kết luận nghiệm thu Jenkins khi có kết quả một build Jenkins thật.

## Review Focus

- Prefix rỗng/sai định dạng hoặc prefix cha: cleanup từ chối trước khi truy cập mạng (Task 1/2).
- Test chết trước dispose: cleanup run vẫn dọn nhánh API/browser, giữ nhánh đối chứng (Task 2/4).
- Workspace có báo cáo cũ: không dùng artifact của build trước làm bằng chứng mới (Task 3).
- API/browser lỗi rồi cleanup cũng lỗi: giữ kết quả thất bại ban đầu và thể hiện cleanup thất bại (Task 3).
- TRX/browser report chứa skipped cases hoặc thiếu ca R2 bắt buộc: không công bố nghiệm thu đạt (Task 2/3).

### Task 1: Prefix lưu trữ và fixture API

**Files:** sửa `src/Modules/Reporting/Infrastructure/ReportingOptions.cs`, `S3ReportStore.cs`; thêm `ReportObjectPrefix.cs` cùng thư mục; sửa `tests/ApiTests/ReportTestStorage.cs`; thêm `tests/ApiTests/ReportObjectPrefixTests.cs`.

**Interfaces:** `ReportingOptions.KeyPrefix` mặc định `""`; `ReportObjectPrefix.Apply(string prefix, string key): string` xác thực và nối prefix/key. API fixture nhận `TEST_S3_RUN_PREFIX`, đặt object trong `<run>/api/<guid>/`; local không có biến này vẫn dùng `ekt-tests/<guid>/`.

- [ ] Viết và chạy test đỏ cho prefix mặc định giữ nguyên key, prefix hợp lệ nối đúng, từ chối slash đầu, `..`, backslash và key thoát phạm vi.
- [ ] Thêm `KeyPrefix`, áp dụng cùng cách cho Put/Get; sửa fixture để Head/Delete và Dispose dùng đúng key vật lý, không nối prefix hai lần.
- [ ] Chạy test prefix, cấu hình storage và ca upload/download R2 thật; xác minh bytes/checksum và key dưới prefix mong đợi.

### Task 2: Công cụ CI quản lý run và bằng chứng

**Files:** thêm `tools/R2Ci/R2Ci.csproj`, `Program.cs`, `RunStorage.cs`, `Evidence.cs`; thêm project vào `EducationKeeptrack.slnx`; thêm `tests/ApiTests/R2CiTests.cs` và project reference cần thiết.

**Interfaces:** CLI `init <state-path>`, `cleanup <state-path> <summary-path>`, `evidence <state-path> <trx-path> <browser-json-path> <cleanup-summary-path> <output-path>`. State chứa GUID run và prefix, không chứa secrets; mọi lệnh dùng `TEST_S3_*` từ environment. `init` từ chối state đã có; cleanup chỉ chấp nhận prefix tái tạo được từ run ID hợp lệ.

- [ ] Viết và chạy test đỏ cho state thiếu/sai, prefix cha, báo cáo thiếu, skipped/failed tests, thiếu các nhóm ca PDF bắt buộc và summary cleanup thất bại.
- [ ] Implement CLI dùng SDK hiện có; kiểm tra bốn biến R2 bắt buộc, endpoint HTTPS và timeout. Cleanup List/Delete theo prefix sở hữu, đọc lại từ đầu sau mỗi batch, kiểm tra key trước xóa; không gọi API bucket lifecycle.
- [ ] Tổng hợp bằng chứng từ allowlist tên test/kết quả/count, không sao chép exception, URL hay stdout từ báo cáo thô; ghi output thành công chỉ sau kiểm tra đủ API/browser và cleanup.
- [ ] Kiểm thử R2 thật với hai prefix thuộc bài test: cleanup prefix A rồi xác minh object prefix B còn đọc được; dọn B trong finally. Test object mồ côi trong các nhánh API/browser.

### Task 3: Pipeline, browser và hướng dẫn chạy

**Files:** sửa `Jenkinsfile`, `ui/e2e/monthly-reports.spec.ts`, `ui/playwright.config.ts`, `.gitignore`, `doc/cloudflare-r2.md`; thêm `docs/verification/R2-Jenkins.md` và script trong `tools/ci/` nếu cần chia phần chạy.

**Interfaces:** credentials IDs `ekt-ci-r2-endpoint`, `ekt-ci-r2-bucket`, `ekt-ci-r2-access-key`, `ekt-ci-r2-secret-key`; giữ credentials database/demo hiện có. State/report raw thuộc thư mục riêng của run; chỉ evidence đã lọc được archive.

- [ ] Bổ sung browser assertion độ dài và SHA-256 bytes tải về bằng metadata API, xem test thất bại khi cố ý dùng checksum sai rồi khôi phục assertion đúng.
- [ ] Sau build, cài Chromium .NET với system dependencies trước API tests; cài riêng Chromium UI theo package Playwright của UI. Dùng thư mục cache trình duyệt cố định trong run.
- [ ] Bind R2 bằng `withCredentials`, `set +x` trước xử lý secrets; init run và map `TEST_S3_*` sang `Reporting__*`; API và browser dùng nhánh prefix riêng cùng run.
- [ ] Chạy API tests với TRX mới, rồi browser suite tuần tự với JSON reporter mới; backend chạy với logging an toàn, chờ sẵn sàng có timeout, trap dừng và chờ backend thoát trước cleanup.
- [ ] `post/always` luôn thử cleanup R2 và database bằng các khối độc lập, kể cả test fail. Tổng hợp evidence từ kết quả mới và trạng thái cleanup; lỗi cleanup không được đổi build thất bại thành thành công. Archive bản tổng hợp/báo cáo đã lọc; không archive raw TRX/JSON/logs/PDF/trace.
- [ ] Ghi hướng dẫn agent Linux, credentials, pre-provisioned bucket, cách chạy local cùng CLI và xử lý run bị gián đoạn; phân biệt pipeline đã sửa với pipeline đã nghiệm thu thật.

### Task 4: Kiểm chứng toàn bộ và bàn giao

**Files:** cập nhật tiến độ trong plan này và kết quả trong `docs/verification/R2-Jenkins.md`.

- [ ] Chạy `dotnet build EducationKeeptrack.slnx -c Release`; chạy API suite với PostgreSQL/R2 thật, không chạy build chồng lên testhost.
- [ ] Trong `ui`, chạy `npm run typecheck`, `npm run build`, `npx playwright test --workers=1` với backend test thật.
- [ ] Chạy CLI cleanup/evidence trên kết quả mới; kiểm tra thiếu secrets/artifacts, skipped tests và lỗi cleanup làm lệnh trả mã lỗi, output không lộ secrets/token.
- [ ] Kiểm tra cú pháp script, `git diff --check` và review phạm vi diff; chỉ cập nhật tài liệu bằng các kiểm tra đã chạy thực tế.
- [ ] Nếu có Jenkins endpoint/credentials quản trị trong môi trường đã được cho phép, validate và chạy job thật. Nếu chưa có, ghi rõ chưa nghiệm thu Jenkins và không đóng #29.
